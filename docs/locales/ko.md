> "엄격한 하드 리얼타임 안전성, 음향학적 수학적 정밀성, 그리고 손끝으로 체감되는 물리 음향 모델링."

저는 오디오 디지털 신호 처리(DSP) 및 시스템 소프트웨어 엔지니어로, 하드 리얼타임 공간 음향학, 바이노럴 심리음향 렌더링, 물리 모델링 사운드 신서시스를 전문으로 연구·개발하고 있습니다. 초저지연 오디오 플러그인(CLAP / VST3), SIMD 가속 필터링 파이프라인, 베어메탈 및 리눅스 임베디드 오디오 런타임, 그리고 몰입형 다채널 음향을 위한 오픈 수학적 알고리즘을 구축하는 데 집중하고 있습니다.

상용 플러그인 개발 외에도 DIY 유로랙(Eurorack) 모듈 제작, 고유 잔향 특성을 가진 건축 공간 임펄스 응답(IR) 측정, 서브 밀리초 오디오 콜백을 위한 락프리(Lock-Free) 버퍼 아키텍처 연구를 꾸준히 이어가고 있습니다.

---

## 🧭 엔지니어링 철학

- **엄격한 오디오 스레드 안전성(Hard Real-Time)**: 오디오 콜백 루프는 절대로 방해받아서는 안 됩니다. 동적 메모리 할당(`malloc`/`new`), 뮤텍스 락(`mutex`), 파일 및 네트워크 I/O, 우선순위 역전(Priority Inversion)이나 버퍼 언더런(xrun)을 유발할 수 있는 어떠한 스레드 동기화도 원천 배제합니다.
- **정적 샘플링을 뛰어넘는 물리 모델링**: 수십 기가바이트의 고정된 PCM 샘플 테이블을 읽어오는 대신, 진동하는 금속 현, 공명하는 기주(Air Column), 미세 진동하는 막, 공간 반사음의 연속 미분 파동 방정식을 실시간 수치 해석으로 직접 계산합니다.
- **데이터 지향 SIMD 벡터화**: 오디오 버퍼 구조를 SoA(Struct-of-Arrays) 형태로 설계하여 8-wide AVX2 / AVX-512 및 ARM NEON 벡터 명령어를 극대화하며, 분기 예측 실패 없이 연속된 캐시 라인 상에서 부동소수점 오디오 블록을 고속 연산합니다.
- **개방형 표준과 모듈형 사운드 그래프**: CLAP 플러그인 규격, 인터리브되지 않은 IEEE 32/64비트 실수 스트림, 마이크로컨트롤러부터 대규모 DAW까지 무결하게 구동되는 모듈형 노드 그래프 아키텍처를 지향합니다.

## 🚀 주요 오픈소스 프로젝트

### 1. `reson-dsp` — 락프리 물리 모델링 도파관 신디사이저
- **주 사용 언어**: C++23 / CLAP API
- **프로젝트 개요**: 2D 디지털 도파관 네트워크를 활용하여 타격된 금속 막대, 벨, 비선형 탄성 현의 음향 공명을 실시간 시뮬레이션하는 다성(Polyphonic) 신서시스 엔진.
- **핵심 특징**:
  - 컴파일 타임 크기 제한 락프리 링 버퍼를 통한 결정론적 $O(1)$ 보이스 할당.
  - 오디오 처리 라이프사이클 전반에 걸쳐 힙 메모리 할당(Zero Allocation) 배제.
  - AVX-512 및 ARM NEON 벡터화된 바이쿼드 필터 캐스케이드로 192 kHz 샘플레이트에서 단일 코어 2.8% 미만의 CPU 점유율 달성.

### 2. `spatial-orb` — 실시간 바이노럴 앰비소닉스 3D 공간음향 엔진
- **주 사용 언어**: Rust / WebAssembly
- **프로젝트 개요**: 다채널 고차 앰비소닉스(최대 5차 HOA, 36개 구면 조화 함수) 신호를 사용자 맞춤 HRTF 프로파일을 통해 헤드폰용 바이노럴 입체 음향으로 렌더링하는 3D 공간화 엔진.
- **핵심 특징**:
  - 분할 중첩 보존(Partitioned Overlap-Save) 고속 컨볼루션으로 1.2ms 이하의 초저지연 처리.
  - 지퍼 노이즈 없는 매끄러운 파라메트릭 도플러 효과 및 거리 감쇠 알고리즘.
  - 네이티브 정적 라이브러리(`.a` / `.so`)와 브라우저 WebAudio AudioWorklet용 WebAssembly 이중 타깃 컴파일.

### 3. `wav-crunch` — SIMD 64비트 오디오 분석 및 폴리페이즈 리샘플러 CLI
- **주 사용 언어**: Rust
- **프로젝트 개요**: 외부 의존성 없는 고성능 CLI 도구로, 비트 단위 오디오 정밀 분석, 인터샘플 피크 감지(4배 오버샘플링 True Peak), 초고음질 샘플레이트 변환 지원.
- **핵심 특징**:
  - 144 dB 이상의 신호 대 잡음비(SNR)를 보장하는 동적 윈도우 폴리페이즈 싱크(Sinc) 보간.
  - 캐시 라인 정렬 작업 훔치기(Work-Stealing) 스레드 풀 기반의 초고속 배치 처리.
  - ITU-R BS.1770-4 표준 기반 LUFS 음량 분석, 동적 범위 측정, 위상 상관도 매트릭스 리포트 생성.

### 4. `patch-wire` — 마이크로 모듈러 오디오 신호 그래프 런타임
- **주 사용 언어**: C++20 / C
- **프로젝트 개요**: 임베디드 리눅스(라즈베리 파이 CM4, Bela) 및 유로랙 디지털 모듈에 최적화된 초경량 방향성 비순환 그래프(DAG) 오디오 연산 엔진.
- **핵심 특징**:
  - 그래프 설정 단계에서 1회 위상 정렬(Topological Sort)을 완료하여 내부 오디오 블록 루프 내 분기 평가 제거.
  - 단일 연속 캐시 정렬 메모리 아레나에 전체 노드 그래프 메모리를 배치하여 엄격한 정적 메모리 한계 보장.
  - 하드웨어 CV/Gate 제어 전압 I/O와 실시간 SPI/I2C ADC 버스 드라이버 동기화.

```text
[ 물리 하드웨어 드라이버 (ALSA / ASIO / CoreAudio) ]
                        |
                        v (인터럽트 / 오디오 콜백)
+-------------------------------------------------------------------+
|                     오디오 스레드 콜백                             |
|                                                                   |
|   +-----------------------------------------------------------+   |
|   | 1. 락프리 SPSC FIFO 입력 인출 (대기/락 없는 무지연 인출)   |   |
|   +-----------------------------------------------------------+   |
|                               |                                   |
|   +-----------------------------------------------------------+   |
|   | 2. SIMD 블록 연산 (벡터화된 DSP 필터 / DWM 물리 모델링)   |   |
|   |    - 64샘플 단위 버퍼 블록                                |   |
|   |    - SoA 부동소수점 레지스터 (AVX-512 / NEON)             |   |
|   +-----------------------------------------------------------+   |
|                               |                                   |
|   +-----------------------------------------------------------+   |
|   | 3. 바이노럴 HRTF 분할 고속 컨볼루션 연산                  |   |
|   |    - 시간 영역 중첩 보존 버퍼                             |   |
|   +-----------------------------------------------------------+   |
|                               |                                   |
|   +-----------------------------------------------------------+   |
|   | 4. 포화 리미터 및 디더링 ➔ DAC 출력 링 버퍼 기록          |   |
|   +-----------------------------------------------------------+   |
+-------------------------------------------------------------------+
                        |
                        v
          [ 물리 DAC / 헤드폰 출력 ]
```
