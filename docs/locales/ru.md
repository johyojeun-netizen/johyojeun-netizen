> "Строгая надежность в жестком реальном времени, математическая акустическая точность и осязаемое физическое моделирование звука."

Я инженер по цифровой обработке сигналов (ЦОС / DSP) и системный разработчик, специализирующийся на пространственной акустике жесткого реального времени, бинауральном психоакустическом рендеринге и физическом синтезе звука. Моя основная деятельность сосредоточена на создании аудиоплагинов со сверхнизкой задержкой (CLAP / VST3), SIMD-векторизованных вычислительных конвейеров, встраиваемых аудио-сред для bare-metal и Linux, а также открытых математических инструментов для иммерсивных многоканальных звуковых полей.

Помимо коммерческой разработки плагинов, я проектирую аналоговые и цифровые модули для синтезаторов формата Eurorack, измеряю импульсные отклики (IR) в акустически уникальных архитектурных пространствах и исследую неблокирующие (lock-free) кольцевые буферы для субмиллисекундных аудиоколбэков.

## 🧭 Инженерная философия

- **Бескомпромиссная надежность в аудиопотоке (Hard Real-Time)**: Цикл аудиоколбэка неприкосновенен. Никаких динамических выделений памяти (`malloc`/`new`), никаких мьютексов (`mutex`), никаких операций дискового или сетевого ввода-вывода и никакой синхронизации потоков, способной вызвать инверсию приоритетов или опустошение буфера (xrun).
- **Физическое моделирование вместо статичного сэмплирования**: Вместо воспроизведения статичных гигабайтных PCM-таблиц мы численно решаем в реальном времени непрерывные дифференциальные волновые уравнения физических сред — вибрирующих струн, резонирующих воздушных столбов, мембран и акустических отражений помещения.
- **Данно-ориентированная SIMD-векторизация**: Структурирование аудиобуферов по модели SoA (Struct-of-Arrays) для полноценного использования 8-канальных векторных инструкций AVX2 / AVX-512 и ARM NEON, обрабатывающих непрерывные массивы чисел с плавающей запятой в строках кэш-памяти без промахов предсказателя переходов.
- **Открытые стандарты и модульные графы сигналов**: Безусловный приоритет открытых стандартов (спецификация CLAP, чередующиеся потоки IEEE 32/64-бит с плавающей запятой) и модульных графов вычислений (DAG), работающих как на микроконтроллерах, так и в профессиональных цифровых аудиостанциях (DAW).

## 🚀 Ключевые проекты с открытым исходным кодом

### 1. `reson-dsp` — Неблокирующий полифонический волноводный синтезатор
- **Язык**: C++23 / CLAP API
- **Описание**: Полифонический движок физического моделирования, рассчитывающий акустический резонанс металлических пластин, колоколов и струн с помощью двумерных сеток волноводов.
- **Ключевые особенности**:
  - Детерминированное $O(1)$ распределение голосов через статические неблокирующие кольцевые очереди.
  - Нулевое динамическое выделение памяти из кучи (Zero Heap Allocation) на протяжении всего цикла аудиообработки.
  - Векторизованные через AVX-512 и ARM NEON каскады фильтров с загрузкой менее 2.8% одного ядра процессора при 192 кГц.

### 2. `spatial-orb` — Бинауральный 3D-пространственный аудиодвижок Ambisonics
- **Язык**: Rust / WebAssembly
- **Описание**: Пространственный процессор, декодирующий потоки амбисоники высших порядков (до 5-го порядка HOA, 36 сферических гармоник) в бинауральный звук для наушников с пользовательскими HRTF-профилями.
- **Ключевые особенности**:
  - Секционированная быстрая свертка (Partitioned Overlap-Save) с задержкой обработки менее 1.2 мс.
  - Непрерывный параметрический эффект Доплера и дистанционное затухание без паразитных призвуков и кликов.
  - Двойная компиляция: нативные статические библиотеки (`.a` / `.so`) и WebAssembly для WebAudio AudioWorklet.

### 3. `wav-crunch` — Консольная утилита анализа аудио и полифазный ресэмплинг
- **Язык**: Rust
- **Описание**: Автономный консольный инструмент без внешних зависимостей для побитового анализа качества звука, выявления истинных межсэмпловых пиков (True Peak при 4x оверсэмплинге) и эталонного пересчета частоты дискретизации.
- **Ключевые особенности**:
  - Полифазная sinc-интерполяция с динамическим окном, обеспечивающая отношение сигнал/шум (SNR) более 144 дБ.
  - Параллельная обработка на основе пула потоков с разделением нагрузки (work-stealing) и выравниванием по строкам кэша.
  - Полный экспорт показателей громкости LUFS (стандарт ITU-R BS.1770-4), динамического диапазона и матриц фазовой корреляции.

### 4. `patch-wire` — Микромодульный граф аудиосигналов для встраиваемых систем
- **Язык**: C++20 / C
- **Описание**: Высокопроизводительный движок на базе ориентированного ациклического графа (DAG), спроектированный для встраиваемого Linux (Raspberry Pi CM4, Bela) и автономных цифровых модулей Eurorack.
- **Ключевые особенности**:
  - Однократная топологическая сортировка при конфигурации графа; полное отсутствие ветвлений внутри цикла обработки аудиосэмплов.
  - Фиксированный объем статической памяти: все структуры графа размещаются в непрерывной кэш-выровненной арене памяти.
  - Жесткая аппаратная синхронизация управляющих напряжений CV/Gate через драйверы реального времени для шин SPI и I2C.
