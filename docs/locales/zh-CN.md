> “严苛的硬实时安全、数学音响保真度与可感知的物理声音建模。”

我是一名专注于数字信号处理（DSP）与底层音频系统的软件工程师，研究方向涵盖硬实时空间声学、双耳心理声学渲染以及物理建模声音合成。我的核心工作致力于构建超低延迟音频插件（CLAP / VST3）、SIMD向量化滤波流水线、针对裸机与嵌入式Linux的高确定性音频运行时，以及用于多通道沉浸式声场的开源声学算法。

## 🧭 工程哲学

- **硬实时音频线程安全（Hard Real-Time）**：音频回调函数是绝对受控的计算区域。严禁任何动态内存堆分配（`malloc`/`new`）、互斥锁（`mutex`）、文件或网络I/O，杜绝一切可能诱发优先级反转或缓冲区欠载（xrun）的线程同步机制。
- **物理声学建模胜于静态采样回放**：摒弃占用数十GB静态存储的PCM采样表，转而通过数值微分方程实时模拟真实物理介质的连续波动规律——包括振动琴弦、共振空气柱、薄膜张力以及三维声学空间反射。
- **数据导向与SIMD指令级并行**：将音频数据流设计为结构体数组（SoA）布局，充分利用8通道AVX2 / AVX-512与ARM NEON向量指令集，在连续缓存行上高速计算连续浮点音频块，彻底避免分支预测失败。
- **开放标准与模块化音频图运行时**：坚持拥抱开放技术标准（CLAP插件标准、非交错IEEE 32/64位浮点流），构建轻量级有向无环图（DAG）音频引擎，使算法能够无缝跨越微控制器与专业数字音频工作站（DAW）。

## 🚀 重点开源项目

### 1. `reson-dsp` — 无锁物理建模波导合成器
- **开发语言**：C++23 / CLAP API
- **项目概述**：基于二维数字波导网络构建的多复音物理建模合成引擎，可实时模拟被敲击的金属棒、钟体以及非线性张力琴弦的物理共振特性。
- **核心特性**：
  - 基于编译期定长无锁环形队列实现确定性 $O(1)$ 复音分配与窃取。
  - 在整个实时音频处理生命周期中实现零堆内存分配（Zero Allocation）。
  - AVX-512与ARM NEON向量化双二阶滤波器级联，在192 kHz采样率下单核心CPU占用率低于2.8%。

### 2. `spatial-orb` — 实时双耳Ambisonics三维声场渲染引擎
- **开发语言**：Rust / WebAssembly
- **项目概述**：将多通道高阶Ambisonics（最高支持5阶HOA，36通道球谐函数）实时解码并结合用户自定义HRTF配置文件转换为高保真双耳耳机声场的3D空间化引擎。
- **核心特性**：
  - 基于分块重叠保留法（Partitioned Overlap-Save）的高速卷积，延迟控制在1.2ms以内。
  - 平滑的参数化多普勒效应与基于物理的距离衰减模型，彻底消除拉链噪声（Zipper Noise）。
  - 双重编译目标支持：本地静态库（`.a` / `.so`）与适用于WebAudio AudioWorklet的高性能WebAssembly模块。

### 3. `wav-crunch` — SIMD 64位音频分析与多相重采样CLI
- **开发语言**：Rust
- **项目概述**：无外部依赖的高性能命令行音频处理工具，支持位级精度音频质量分析、帧间真实峰值检测（4倍过采样True Peak）以及高保真采样率转换。
- **核心特性**：
  - 基于动态加窗Sinc函数的多相插值重采样算法，信噪比（SNR）超过144 dB。
  - 基于缓存行对齐的任务窃取（Work-Stealing）线程池实现高并发批处理。
  - 完整导出ITU-R BS.1770-4标准的LUFS响度指标、动态范围（DR）以及相位相关性矩阵。

### 4. `patch-wire` — 嵌入式微模块化音频信号图运行时
- **开发语言**：C++20 / C
- **项目概述**：专为嵌入式Linux系统（Raspberry Pi CM4、Bela）和无显示界面Eurorack数字模块定制的轻量级有向无环图（DAG）音频计算图引擎。
- **核心特性**：
  - 图配置阶段一次性完成拓扑排序，内部音频块循环中完全消除条件分支判断。
  - 节点图全局内存布局映射至单一连续缓存对齐的内存池，严格保证静态内存上界。
  - 硬件模拟CV/Gate控制电压输入输出与实时SPI/I2C ADC总线底层驱动直接同步。
