> 「厳格なハードリアルタイム安全性、数学的音響の忠実度、そして触覚的な物理音響モデリング。」

私は音声デジタル信号処理（DSP）およびシステムソフトウェアを専門とするエンジニアです。ハードリアルタイム空間音響、バイノーラル心理音響レンダリング、物理モデリング音響合成の研究開発に専念しています。主に超低レイテンシ・オーディオプラグイン（CLAP / VST3）、SIMDベクトル化フィルタリングパイプライン、ベアメタルおよび組み込みLinux向けオーディオランタイム、高密度マルチチャンネル音響向けオープンアルゴリズムの開発を手がけています。

商用プラグイン開発のほか、DIYモジュラーシンセ（ユーロラック）の回路設計、建築空間のインパルス応答（IR）測定、サブミリ秒オーディオコールバックのためのロックフリー（Lock-Free）バッファ構造の研究を継続しています。

## 🧭 エンジニアリング哲学

- **厳格なオーディオ・スレッド安全性（Hard Real-Time）**: オーディオコールバックループは不可侵です。動的メモリ確保（`malloc`/`new`）、ミューテックス（`mutex`）、ファイルおよびネットワークI/O、優先度逆転やバッファアンダーラン（xrun）を招くあらゆるスレッド同期処理を完全に排除します。
- **静的サンプリングを超える物理モデリング**: 数十ギガバイトの静的なPCMサンプルテーブルに頼るのではなく、振動する金属弦、共鳴する気柱、薄膜、空間反射の連続微分波動方程式をリアルタイム数値解析によって直接計算します。
- **データ指向SIMDベクトル演算**: オーディオバッファをSoA（Struct-of-Arrays）構造で設計し、8レーンAVX2 / AVX-512およびARM NEONベクトル命令を最大限に活用。分岐予測ミスを起こさず、連続キャッシュライン上で浮動小数点オーディオブロックを高速並列演算します。
- **オープン規格とモジュラー音響グラフ**: CLAPプラグイン仕様、非インターリーブIEEE 32/64ビット浮動小数点ストリーム、マイコンから大規模DAWまでシームレスに動作するモジュラーノードグラフエンジンを採用します。

## 🚀 主要オープンソースプロジェクト

### 1. `reson-dsp` — ロックフリー物理モデリング導波管シンセサイザー
- **言語**: C++23 / CLAP API
- **概要**: 2次元デジタル導波管ネットワークを用いて、打撃された金属棒、ベル、非線形な弦の共鳴音響をリアルタイムに数値シミュレーションするポリフォニック音響エンジン。
- **特徴**:
  - コンパイル時サイズ確定のロックフリー循環キューによる決定論的 $O(1)$ ボイスアロケーション。
  - オーディオ処理ループ内でのヒープメモリ確保（Zero Allocation）を完全徹底。
  - AVX-512およびARM NEONベクトル化バイクアッドフィルタカスケードにより、192 kHz動作時でも単一コアCPU負荷2.8%未満を実現。

### 2. `spatial-orb` — リアルタイム・バイノーラルAmbisonics 3D空間音響エンジン
- **言語**: Rust / WebAssembly
- **概要**: 最大5次HOA（36球面調和関数）の多チャンネル音響信号を、個別HRTFプロファイルを用いてヘッドフォン用バイノーラル立体音響へ変換するリアルタイム空間音響エンジン。
- **特徴**:
  - 分割オーバーラップセーブ（Partitioned Overlap-Save）高速畳み込みにより1.2ms未満の超低遅延を達成。
  - ジッパーノイズのない滑らかなパラメトリック・ドップラー効果および距離減衰アルゴリズム。
  - ネイティブ静的ライブラリ（`.a` / `.so`）およびWebAudio AudioWorklet向けWebAssemblyへのデュアルコンパイル。

### 3. `wav-crunch` — SIMD 64ビット音声解析・多相リサンプラCLI
- **言語**: Rust
- **概要**: 外部依存関係ゼロの高精度コマンドラインツール。ビット精度音声解析、インターサンプルピーク検出（4倍オーバーサンプリングTrue Peak）、高忠実度サンプリングレート変換を提供。
- **特徴**:
  - 144 dB以上のSNR（SN比）を誇る動的窓関数付き多相Sinc補間アルゴリズム。
  - キャッシュライン整合のワークスティーリング・スレッドプールによる高速バッチ処理。
  - ITU-R BS.1770-4準拠のLUFSラウドネス測定、ダイナミックレンジ測定、位相相関行列レポート出力。

### 4. `patch-wire` — マイクロモジュラー音響シグナルグラフ・ランタイム
- **言語**: C++20 / C
- **概要**: 組み込みLinux（Raspberry Pi CM4、Bela）およびユーロラック・デジタルモジュール向けに特化した超軽量DAG（有向非巡回グラフ）音響演算エンジン。
- **特徴**:
  - グラフ構成時にトポロジカルソートを完了し、オーディオブロック内部ループでの条件分岐評価をゼロ化。
  - ノードグラフ全体のメモリを単一のキャッシュ整列メモリ空間に固定配置し、静的フットプリントを厳格保証。
  - ハードウェアCV/Gate電圧I/OとリアルタイムSPI/I2C ADCバスドライバの同期処理。
